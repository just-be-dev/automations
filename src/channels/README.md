# Channels

The slack channel implemented here uses [effect-channels](https://github.com/humanlayer/effect-channels) from [human-layer](https://www.humanlayer.dev/).

# What is a channel?

Channels are a connection to a 3rd party service that is both bi-directional and stateful. Typically this means something like a conversation.

Vercel's [eve agent docs](https://eve.dev/docs/channels/overview) explain the concept fairly well.
